# Makerlab Return Processor v0.4.17-test

## Interface enhancements
- Introduced rounded, opaque content cards for easier reading over Windhawk glass effects.
- Added rounded action buttons with hover and clear disabled states.
- Improved responsive action layout: buttons stretch across columns and rearrange at compact window widths.
- Applied matching treatment to Scan History & Recovery.

- All Shopee, Lazada, TikTok, Odoo, Lark, and JSON recovery logic remains unchanged.
- This is a test/pre-release build. Test the live appearance with your Windhawk Windows setup before publishing a stable release.
